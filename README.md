# Railguns

Railguns is a single-file HTML game/app with neon railgun cards, local login, inventory, updates, settings, and an RNG railgun roll game.

## Open The App

Open `railguns.html` in a browser.

`Railgun.html` is included as a small redirect for the old filename.

## Features

- V1 to V6 railguns, plus V6 Lite
- Neon stat bars for speed, accuracy, power, and fling
- Free railgun ordering
- Inventory with separate Railguns and RNG tabs
- Delete unwanted inventory items
- RNG rolling with V6 as a 10% drop
- V5, V6 Lite, and V6 wall shatter reveal
- V6 white nuke crumble effect
- Local Login / Sign Up
- Google, Apple, Xbox, and Roblox quick auth profiles
- Updates panel
- Settings panel with sound, background music, low-lag mode, fling mode, sign out, and delete account

## Auth Note

This project runs from a local static HTML file, so Google, Apple, Xbox, and Roblox auth are local demo profiles. Real OAuth login needs a backend server and provider setup.
